# Titanic Survival Prediction 🛳️

Easy beginner-friendly machine learning project where I predict whether a passenger survived the Titanic disaster using 
data from [Kaggle Titanic competition](https://www.kaggle.com/competitions/titanic).

## 🔍 Project Overview

- Used pandas for data cleaning
- Visualized patterns with seaborn and matplotlib
- Trained and compared Logistic Regression and Random Forest classifiers
- Analyzed feature importance to understand what affects survival

## 📊 Technologies Used

- Python
- pandas, seaborn, matplotlib
- scikit-learn
- Google Colab

## 🧠 Key Findings

- `Sex`, `Pclass`, and `Fare` were strong indicators of survival
- Random Forest gave better accuracy than Logistic Regression
